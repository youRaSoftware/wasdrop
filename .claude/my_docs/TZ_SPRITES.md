# ТЗ: спрайты фруктов + реакция на падение

## 1. Ассеты

Папка: `features/assets/images/fruits/` (объявить в `features/pubspec.yaml` → `flutter: assets:`).

Файлы, по 2 состояния на тир (пока есть только яблоко — подключить его для ВСЕХ тиров как заглушку, чтобы проверить механику):

```
fruits/t5_idle.png    — рот закрыт (спокойное)
fruits/t5_squish.png  — рот открыт (уже сгенерирован пользователем)
```

Требования к PNG: 512×512, прозрачный фон (у сгенерированных файлов фон белый — удалить, например в Higgsfield remove background), фрукт вписан в круг ~95% ширины кадра, центр тела = центр кадра (стебель/листик могут выступать за круг — это ок, физическая форма считается по телу: круг для круглых фруктов, скруглённый многоугольник для вытянутых вроде винограда, лимона и клубники — см. CLAUDE.md, «Спрайты фруктов»). Фрукт можно рисовать вытянутым или с носиками, физика подстроится сама; главное — без теней под телом.

## 2. Загрузка в движке

`BallBody.render` сейчас рисует градиентный круг + эмодзи. Заменить на спрайты:

- В `WasDropGame.onLoad`: `await images.loadAll([...])`, кэш `Map<BallTier, Sprite> idle / squish`.
- Если файла для тира нет — fallback на текущую отрисовку (градиент+эмодзи), НЕ падать.
- Рисовать спрайт размером `2r × 2r` с центром в центре тела; поворот тела применяется как есть (фрукты крутятся — это норм).

## 3. Реакция на падение (squash + открытый рот)

В `BallBody`:

- `beginContact`: если `contact` не merge-контакт, на следующем physics-step взять `body.linearVelocity` ДО удара (сохранять в `update`) и если |v| > 60 мировых ед./с — триггерить `_squish()`.
- `_squish()`: 
  - переключить спрайт на `squish`;
  - масштаб тела (только визуальный, не фикстуру): 1.12 по X, 0.88 по Y, возврат к 1.0 за 250 мс с curve `easeOutBack` (Flame `ScaleEffect` на спрайт-компонент или ручная интерполяция в render);
  - через 300 мс вернуть спрайт `idle`;
  - повторный триггер не чаще чем раз в 400 мс (debounce).
- Слияние: оба шара переключаются на `squish` в кадре перед удалением (уже есть вспышка в TODO — согласовать).

## 4. Проверка

1. Бросить шар с высоты — при ударе о дно/кучу яблоко «ойкает»: сжатие + открытый рот, через ~0.3 с спокойное лицо.
2. Лёгкое перекатывание НЕ триггерит реакцию (порог скорости).
3. FPS не проседает: спрайты загружены один раз, никаких загрузок в render/update.

## 5. Когда будут все 11 фруктов

Именование: `t1_idle.png … t11_idle.png`, `t1_squish.png … t11_squish.png` (тиры: вишня, клубника, мандарин, лимон, яблоко, киви, черника, виноград, персик, дыня, арбуз). Убрать fallback-заглушку «яблоко для всех» — оставить fallback только на градиент+эмодзи.
