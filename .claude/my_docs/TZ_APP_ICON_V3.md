# ТЗ: иконка приложения Fruity Drop, версия 3 (без арбуза)

> Для Claude Design (2026-09-17). **Реализовано 2026-09-17**: пришёл вариант «пирамидка» (персик, яблоко, вишня на голубом), разложен в `store/`, iOS/Android наборы, DEV-плашка и экраны запуска перегенерированы. Причина: App Review отклонил приложение по 4.1(a) Copycats — «icons … include references to Suika Game». Иконка Suika Game — улыбающийся арбуз с лицом, и обе наши прошлые иконки (арбуз с мелкими фруктами на мятном фоне; смеющийся арбуз во весь кадр на оранжевом) читаются как тот же образ. **Новая иконка не должна содержать арбуз и вообще не должна строиться вокруг одного большого зелёного полосатого фрукта.**

## Что нужно

Пак как в прошлый раз (appicon.co-совместимый): `appstore.png` 1024×1024 без прозрачности и без скруглений, `playstore.png` 512×512, `android/adaptive-foreground.png` 1024×1024 с прозрачным фоном (объект в центральных 66 %), `Assets.xcassets/AppIcon.appiconset/` со всеми размерами, `AppIcon.icon/` для Icon Composer. Плюс исходник в слоях, если возможно.

## Идея

Иконка про **компанию фруктов и стакан**, а не про один фрукт. Два варианта на выбор, сделать оба:

**Вариант A — «Стакан».** Стеклянный стакан игры (форма классики: прямые стенки, скруглённое дно, стенка `#D9CFBB`, заливка `#ECE5D6` с лёгкой прозрачностью), в нём куча из 4–5 мелких фруктов с лицами: вишня, клубника, мандарин, лимон, сверху выглядывает яблоко. Над стаканом падает ещё одна вишня. Фрукты крупные, лица читаемые на 60 px. Композиция по центру, стакан занимает ~75 % высоты.

**Вариант B — «Клубника-маскот».** Крупная клубника с лицом (из спрайта `t2_idle.png`, 3/4 кадра), рядом снизу выглядывают вишня и мандарин. Клубника — самый узнаваемый и «не арбузный» фрукт набора; красный на кремово-оранжевом фоне контрастен в App Store.

В обоих вариантах: **никакого арбуза, никакой дыни** (полосатые зелёные фрукты исключены полностью), никаких надписей.

## Стиль

Как у спрайтов (`features/assets/images/fruits/t*_idle.png` — использовать их как основу, не перерисовывать): кавай, толстый тёмно-коричневый контур `#33291A`, плоские заливки с мягким бликом, розовые щёчки, большие глаза. Фон — тёплый градиент игры: кремовый `#F7F2E7` → персиковый `#FFD9A8` (или оранжевый акцент `#FF8A34 → #F76B15`, если фрукты светлые); 3–4 мягких блика-кружка и пара звёздочек как на старой иконке допустимы. Без текста, без рамок, без теней под объектами за пределами картинки.

Проверить читаемость на 60×60 (домашний экран) и 29×29 (настройки): лица должны угадываться, силуэт стакана — узнаваться.

## Что сделаю в проекте после получения

`store/` → prod-наборы iOS/Android → `script/gen_dev_icons.sh` (плашка DEV) → `script/gen_launch_images.sh` (экран запуска) → цвета адаптивного фона Android под новый градиент. Скриншоты и промо для сторов тоже будут без арбуза в главной роли (отдельный бриф `STORE_SCREENSHOTS_BRIEF.md`).
