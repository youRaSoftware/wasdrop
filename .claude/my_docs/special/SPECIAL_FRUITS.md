# WasDrop — интеграция режима «Сад чудес» (особые фрукты)

## Ассеты (features/assets/images/special/)
Спрайты 512×512, прозрачный фон, пары idle/squish как у фруктов:
rainbow_idle/squish · bubble_idle/squish · rotten_idle/squish · ice_idle/squish.
Эффекты: bubble_pop.png (брызги), ice_crack.png (осколки), ice_overlay.png (полупрозрачная корка, кладётся ПОВЕРХ спрайта замороженного фрукта, масштаб = диаметр фрукта × 1.15).
Иконка режима: core_ui/assets/icons/garden.svg (24×24, штрих #33291A 1.8).

pubspec (features):
```yaml
flutter:
  assets:
    - assets/images/special/
```

## Модель
```dart
enum SpecialKind { rainbow, bubble, rotten, ice }
class SpecialFruit { final SpecialKind kind; final double radius; }
// радиусы (px спрайта → мир): rainbow 24, bubble 30, rotten 34, ice 20 (лог. как в ТЗ)
```
Особый фрукт — та же сущность, что обычный (кружок в физике), поле kind != null. Форма тела — круг по radius, НЕ по альфе спрайта.

## Спавн (только режим garden)
Очередь бросков: счётчики по фрукту — rainbow каждые ~12 (10–14, равномерный рандом), bubble ~15, rotten ~18 (не раньше 10-го броска), ice ~20. Не больше одного особого в окошках «текущий+следующий» одновременно. В окошке «следующий» — пульсирующее кольцо цвета фрукта (код, 1.2 с цикл, масштаб 1→1.15→1) + бейдж NEW при первой встрече.

## Поведение
- **rainbow**: при первом контакте с любым фруктом тира t → спавнится фрукт t+1 в точке контакта (как обычное слияние, очки за t+1), rainbow исчезает. Контакт с особым фруктом — ничего, лежит дальше.
- **bubble**: гравитация инвертирована (buoyancy: F = -1.3g), всплывает сквозь кучу; фрукты, которых коснулся, получают импульс вверх 0.4 × их вес. Через 5 с после остановки — лопается: анимация bubble_pop (0.3 с, scale 0.6→1.2, fade), очков нет. Вишенка-начинка чисто визуальная.
- **rotten**: collision как обычный, merge-проверка всегда false. Гибнет: (а) от бомбочки, (б) если слияние произошло в радиусе 1.5 × r от неё → +50 очков, анимация — быстрый fade + 3 зелёные искорки.
- **ice**: падает как обычный; при остановке — ближайший фрукт под ним получает frozen=3 (броска), поверх его спрайта рисуется ice_overlay, сам кубик исчезает (анимация ice_crack 0.25 с). frozen-- на каждый бросок игрока; при 0 — ice_crack поверх фрукта, снова сливаемый. Бомбочка снимает лёд мгновенно. Замороженный НЕ участвует в merge-проверке, физика обычная.

## Заказы (2 новых типа)
mergeRainbow(target?) — «Слей Радужку (с виноградом)»; popBubbles(n) — «Лопни N Пузыриков». Появляются только в режиме garden.

## Сейв/рекорды
Снимок партии отдельный (gardenBox в Hive), поля как у классики + kind и frozen у шаров. Лидерборд GC: wasdrop.garden.highscore. Рекорд в меню — на карточке режима.

## Меню
Сетка 2×2 вместо ряда из двух кнопок: На время · Вызов дня · Сад чудес (акцент #C973F0, бейдж NEW до первого входа) · Стаканы. Мини-справка при первом входе: 4 строки «спрайт → одно предложение» (мокап 17d), кнопка «Понятно, играем!».

## Свечение особых (код, не спрайт)
Кольцо цвета: rainbow #C973F0, bubble #5FA8CE, rotten #8FA23B, ice #8FC8E6. В полёте — лёгкий hue-rotate только у rainbow (±20°, 2 с цикл).
