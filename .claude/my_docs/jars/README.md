Исходники из пака Claude Design (`assets_pack/`, c2pa-метаданные вырезаны). SVG 360×540, стенка 15 px, внутренняя область x 35…325, y 0…510. В приложение как SVG не идут: геометрия переводится в `JarShape` (domain), см. `plans/2026-09-17_impl_jars_missions_modes.md`.
